Funciones de Raylib en español 
Traducción al español de las funciones de la biblioteca gráfica Raylib.

Si eres alguien que no entiende bien inglés —como me pasa a mí— acá te traigo las funciones que ya están en la documentación oficial de la librería, 
pero con su explicación traducida al español para que puedas comprender mejor cómo funciona cada cosa.

Es posible que se me haya colado algún error mientras hacía esto. Si llegas a encontrar alguno, me encantaría que me lo hagas saber (si es que alguien 
encuentra este repositorio algún día).
